# 软件内更新参考

[模块导航](README.md)

软件内增量更新不属于当前最小可视化渲染测试仓库范围。当前只提供本地 `cargo panta-package` 生成可搬迁安装目录，没有更新检查、下载、签名清单、Updater helper、自动替换或回滚实现，也没有自动打包发布 workflow。

若未来确有已安装程序更新的需求，先另建任务，明确发行平台、安装布局、信任根与签名、公钥轮换、完整包和增量包策略，以及失败后的恢复边界。用户工程、缓存、日志和个人设置必须与程序安装槽位分开；更新失败应保留有效程序与用户数据。

具体协议、库、进程和界面只在该任务获得明确范围并验证后建立，不在当前仓库预留组件或任务队列。安装目录部署继续遵循[构建与开发](../architecture/build-and-development.md)。
