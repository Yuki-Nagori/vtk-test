# 中文界面与提示文案

[模块导航](README.md) · [UI 与 Bridge](../architecture/ui-and-bridge.md)

## 范围

本仓库直接使用中文界面和中文操作提示。QML 文本、C++ 展示摘要和 Rust 面向用户的提示在实际消费者处维护，不通过语言字典、翻译服务或语言切换设置生成。代码标识、工程字段、稳定错误码与文件格式保持各自的技术契约。

`Settings` 提供系统减少动态效果偏好 `reducedMotion` 与界面布局偏好；不提供当前语言、支持语言列表或语言选择命令。应用启动和构建不依赖语言资源目录、TS / QM 产物或翻译目录安装。

## 文案与职责

QML 直接声明中文按钮、标题、说明和可访问名称；同一动作在菜单、对话框和状态反馈中保持一致。C++ ViewModel 将稳定诊断 code / category / detail 适配为中文摘要，Rust 服务提供可判断的错误类别与必要上下文；业务分支不依赖提示文本。

文件名、用户输入的名称、工程资产名以及 OCCT / Netgen / VTK 等底层库原始诊断保持原值。摘要说明失败原因和下一步操作，必要时附带原始 detail；不对路径、格式标识或第三方输出作隐式字符串替换。拼接路径与动态参数时保留边界，避免把工程内容误当成格式控制符。

源码统一使用 UTF-8。持久化格式、小数点、稳定 ID 和跨语言 DTO 不随显示文本变化。中文字体由 Qt 和系统字体回退负责，不把特定开发机字体路径写入工程。

## 验证

界面改动检查中文标题、按钮、错误和可访问名称是否一致，确认长路径、长工程名和中文混排下的布局、截断和键盘焦点。构建与测试不要求已删除的语言目录或翻译产物；界面文本检查直接针对中文源码和实际窗口，不以语言切换测试代替。
