## 目标与背景

按 034「信息架构 · 主窗口布局」重排主窗口：左栏 `SplitView`（上：资产列表，下：属性面板容器）、页签移到视口上方、底部面板（诊断 / 消息 / 任务）、完整状态栏、分组图标工具栏。现有功能全部保留入口。

[QML 规范](../standards/qml.md)、[Qt 规范](../standards/qt.md)、[图标规范](../standards/icons.md)、[测试规范](../standards/testing.md)、[注释规范](../standards/comments.md)、[提交规范](../standards/commits.md)、[代码生命周期](../standards/code-lifecycle.md)、[UI 与 Bridge 架构](../architecture/ui-and-bridge.md)；设计依据为 [034](034-ui-redesign.md) 对应阶段与「用户决定」。

## 范围与非目标

本次交付：

- 左栏改为 `SplitView`（Q4），宽度 260–480 px 可拖动、可折叠；下半部为属性面板容器，先承载现有侧栏控件。
- `DocumentTabBar` 移到视口上方。
- 底部面板：诊断 / 消息 / 任务三页，可折叠。
- 状态栏：拾取读数、单位、LOD / 流式状态、时间步；侧栏对应旧控件删除。
- 工具栏改为图标 + tooltip 分组（图标先用阶段 0 及临时资源）。
- 左栏 / 底部面板的尺寸与折叠状态写入用户设置（`Settings`），不写工程、不影响 dirty。

非目标：对象树模型（037）、视口色标（038）、主题 token（039）。

## 涉及分组与跨组依赖

Shell（`qml/`）与 Bridge `Settings`（若需新增用户设置键）；不新增跨组依赖。
