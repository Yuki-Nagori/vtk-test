## 现状问题

### 采集环境与限制

- 截图环境：box 上的 Xvfb `:55`（1600×900），debug 构建 `target/native/debug/app/panta`，演示工程 `uidemo`，导入的是 033 用过的 `.pvd` 夹具（3 个时间步，9 节点 / 2 单元，字段 `T`（节点）和 `p`（单元））。
- **视口是空白的**：VTK 使用 WebGPU render window，在 Xvfb 软件渲染下画不出内容，所以截图里的视口全白。视口内的网格、切面、色彩和方向标记都要在真实 GPU 窗口里补截，这一项待验证。
- 截图文件（box 本地，未提交）：`00-empty` 空工作台、`01-newproject` 新建工程、`02-project` 名称校验错误、`03-import` 导入对话框（含系统文件选择器）、`04-imported` 导入 `.pvd` 后、`05-field-popup` 字段下拉。

### 窗口框架与工具栏

| 现象（截图 / 源码） | 问题 | 影响 |
|---|---|---|
| 菜单只有「文件 / 视图 / 网格」三项；「视图」下仅「复位视图」 | 视图预设、面板显隐、主题都没有菜单入口；功能分散在侧栏底部 | 可发现性差，菜单和侧栏功能不对称 |
| 工具栏是 6 个纯文字按钮（新建工程…视口截图），无图标、无分组、无分隔符；按钮宽度跟着文字走 | 和菜单「文件」完全重复，又没有视图、切面、上色这类高频操作 | 工具栏占一整行，信息量却很低 |
| 工具栏右端再显示一次工程名 `uidemo`，窗口标题已是 `uidemo · 可视化渲染测试` | 信息重复，也没有 dirty 标记（标题里才有 `*`） | 占位，容易让人以为右端是可点击的东西 |
| 底部状态栏只有一段 `statusMessage` 和任务进度 | 拾取读数、单位、LOD / 流式状态、当前时间步分散在侧栏和播放栏 | 状态信息没有固定的「家」 |

### 左侧栏（`assetSidebar`，固定 240 px）

导入 `.pvd` 后的截图（`04-imported`）里，侧栏从上到下依次是：模型资产 → 时序动画 → 体网格（信息、切面、法向、位置滑块、字段）→ 网格质量 → 视图与测量（六向视图按钮、拾取提示）。逐项来看：

| 区块 | 现象 | 问题 |
|---|---|---|
| 整体 | 宽度固定 240 px，内容超宽时被**裁切**：体网格信息行截断成 `…（四面`；法向的 Y / Z 输入框和「左 / 右」视图按钮都被截掉一半；「时序动画」行的「打开序列…」按钮在加载网格后被挤出可见区 | 违反 [QML 规范](../standards/qml.md#验证)「禁止以隐藏溢出代替正确布局」；1280×720 下只会更糟 |
| 整体 | 一根长单列，混着「对象」（资产）、「对象属性」（切面、字段、色标）、「全局工具」（视图预设、拾取、质量诊断）和「模式」（时序动画） | 没有「选中对象 → 看它的属性」这种 CAE 软件通用的心智模型；区块显隐随状态变化，布局会跳 |
| 模型资产 | 只是一个平铺列表（`flow`），没有类型图标、可见性开关和层级；派生对象（切面、着色）不出现在列表里 | 多资产时分不清体网格、表面和 STEP 生成物；切面只是一个开关，不是可选中的对象 |
| 时序动画 | 标题和「打开 / 关闭序列」按钮放在资产和体网格之间；033 以后，时间步播放和表面序列已统一到下方的播放栏 | 入口和控件分在两处；按钮被裁切后用户找不到入口 |
| 体网格 · 切面 | 「切面」复选框、「X / Y / Z」表头、三个 −/值/+ 的 SpinBox，加一条无刻度、无数值的位置滑块 | SpinBox 太宽，三个放不下；滑块不显示当前偏移值和单位；预设轴向按钮在窄宽度下不可见 |
| 体网格 · 字段 | 「字段」下拉（`无 / T（节点）/ p（单元）`）；选中后在其下方出现色标（横向渐变条、最小 / 最大、范围模式、缺失值统计） | 色标放在侧栏，离视口很远，截图或录屏时不会被带上；下拉弹出后会盖住下方区块（`05-field-popup`） |
| LOD 状态 | `activeMeshLodStatus` 一行文字夹在体网格和质量之间 | 状态信息没有归到状态栏或诊断区 |
| 网格质量 | 「质量诊断」按钮 + `meshQualityPanel` 的结果表，放在侧栏中部 | 诊断结果和视口高亮之间没有联动入口；结果多时会把视图工具挤到最下面 |
| 视图与测量 | 前 / 后 / 左 / 右 / 顶 / 底 六个大按钮 + 复位 + 拾取读数 | 属于视口工具，却放在侧栏底部；按钮占地大，又被裁切 |

### 视口与页签

| 现象 | 问题 |
|---|---|
| 空工程时，视口是一大块白色区域，没有任何引导（`00-empty`）；侧栏只有一行「导入网格以查看。」 | 首次使用不知道下一步做什么。VTK 背景是浅色渐变（`SetBackground2(0.98, 0.98, 0.98)`），和面板颜色几乎一样，视口边界不明显 |
| 文档页签（`DocumentTabBar`）位于**视口下方**、播放栏上方（`04-imported`） | 和多数桌面软件「页签在内容上方」的习惯相反；播放栏和页签挤在一起，层次不清 |
| 原生 VTK 层压在 QML 之上 | 色标、方向标记、视口工具条、空状态提示都不能用 QML 叠在视口上（[可视化架构](../architecture/visualization.md)），只能在 VTK 里画，或者放在视口矩形外 |

### 播放栏（`PlaybackBar`，033）

| 现象 | 问题 |
|---|---|
| 首帧、末帧、暂停按钮用的是 Unicode 字形 `⏮ ⏭ ⏸`，在截图环境里显示成**方框（豆腐块）**；`◀ ▶ ▶| ⟲` 能显示 | 依赖系统字体回退，在缺少该字形的机器上按钮不可辨认。按[图标规范](../standards/icons.md)应改用 SVG 图标。**这是 033 留下的显示缺陷**，本文只记录，修复放在阶段 0 |
| 「循环」开关只是一个 `⟲` 按钮，开 / 关状态只靠底色区分 | 违反图标规范「颜色不单独表达选中状态」 |
| 时间值 `t = 1` 和帧率 SpinBox（−/10/+）紧挨着 | 帧率没有单位（fps），容易被当成时间值；状态行 `时间步 3 / 3；t = 1；开启切面并选择字段后，结果随时间步更新` 很长，又和底部状态栏重复 |
| 没有播放源时整栏隐藏，`visible` 由 `playbackActive` / `playbackUnavailable` 控制，已核实 | 行为正确；但出现和消失会让视口高度跳动 |

### 对话框

| 对话框 | 现象 | 问题 |
|---|---|---|
| 新建工程（`01`、`02`） | 名称框占位文字「我的工程」颜色接近正文；名称非法时，对话框内和底部状态栏**同时**显示错误 | 占位文字看起来像已填好的值；错误重复出现 |
| 导入（`03`） | 文件框只读，只能点「浏览」；网格类型、单位默认「双层面」/「毫米」，选中 `.pvd` 后类型自动变为「实体 3D」，单位仍是毫米；「近似尺寸」只显示数字；对话框下半部是大片空白 | 拖放已有（task 018 `handleDrop`，原生视口区域的事件归属仍待真实窗口复核），但不能粘贴路径；单位缺少依据（应提示「按包围盒推测」）；布局松散 |
| 系统文件选择器 | QtQuick `FileDialog` 的非原生实现：Home / Desktop / Open / Cancel / Filter 等是**英文**，日期格式 `24 10 2026`；面包屑点击不跳转、双击响应有延迟（自动化时观察到，真实用户环境待验证） | 和全中文界面混杂；交互不可靠 |
| 通用 | 每个对话框都是独立的 `DialogWindow`，自绘标题栏，大小、按钮位置不统一（确定在右下，但宽度不同） | 视觉不统一；部分对话框其实可以改成属性面板里的内联编辑 |

### 交互与反馈

- 时序播放时，切面、导出、诊断被禁用，但界面没有就地解释原因，只在状态栏或播放状态行提示一次。
- 视口操作的鼠标映射是「滚轮缩放、右键旋转、左键拾取」（[可视化架构](../architecture/visualization.md)），界面上没有任何说明，也和 ParaView 的「左键旋转」习惯不同。
- 快捷键只有新建、打开、保存等几项（`App.qml` 中的 `Shortcut`），视图预设、切面、播放都没有快捷键。
- 只有浅色主题；`App.qml` 里仍有少量写死的数值，色标的三个渐变点由 VM 提供，只能是固定的三段色。

结论：采用 **「对象树 + 上下文属性面板 + 中央视口 + 视口下方时间轴 + 可折叠底部诊断区」**，也就是 ParaView、STAR-CCM+、CFD-Post 的共同骨架。保持本应用「即改即显」、无 Apply 的交互；色标学 ParaView，由 VTK 在视口内绘制。

### 主窗口布局（设计）

```text
│ 菜单栏：文件  编辑  视图  网格  结果  帮助                                    │
├──────────────────────────────────────────────────────────────────────────┤
│ 工具栏（图标+tooltip，分组）：工程 | 导入/导出 | 视图预设 复位 | 切面 字段 | 截图   │
├───────────────┬──────────────────────────────────────────────────────────┤
│ 对象树         │ 文档页签：flow ×  wing ×                                  │
│  ▾ uidemo      ├──────────────────────────────────────────────────────────┤
│   ▾ flow 👁    │                                                          │
│     ◦ 切面 👁  │                 VTK 视口（深色渐变背景）                    │
│     ◦ 着色: T  │     色标（VTK scalar bar）              方向标记（VTK）     │
│   ▸ wing 👁    │                                                          │
├───────────────┤                                                          │
│ 属性面板        ├──────────────────────────────────────────────────────────┤
│ [属性|显示|信息]│ 播放栏：⏮ ◀ ▶ ▶| ⏭ 🔁  ━━━━━●━━  t = 1.00 s   10 fps        │
│  …按选中对象变化 ├──────────────────────────────────────────────────────────┤
│               │ 底部面板（可折叠）：[诊断] [消息] [任务]                      │
├───────────────┴──────────────────────────────────────────────────────────┤
│ 状态栏：就绪 | 拾取 (x,y,z) | 单位 mm | LOD/流式 | 时间步 3/3 | 任务进度 取消      │
└──────────────────────────────────────────────────────────────────────────┘
```

- 左栏使用 Qt Quick `SplitView`：上为对象树，下为属性面板，宽度可拖动（默认 300 px，最小 260 px），左栏整体可折叠。原因见待决问题 Q4。
- 中央区是 `ViewportPane`，页签移到视口上方；播放栏紧贴视口下边，保持 033 的「避开视口矩形」原则。
- 底部面板默认折叠成一行标题；诊断有新结果或任务出错时自动展开一次。
- 状态栏是状态信息的唯一归宿，侧栏里的 LOD 状态、拾取读数和播放状态行都移到这里。

### 对象树（管线树）

| 层级 | 节点 | 来源（现有能力） | 节点操作 |
|---|---|---|---|
| 0 | 工程 | 工程快照 | 重命名、保存、属性：路径与单位 |
| 1 | 网格资产（表面 / 体网格 / STEP 生成体网格，用图标区分） | `MeshAssetRef` | 可见性（眼睛）、激活（打开页签）、导出、删除 |
| 2 | 切面 | 024 任意平面切面（每个体网格一个） | 可见性、属性：法向 / 位置 / 预设 |
| 2 | 字段着色 | 029 结果场 + 033 色标 | 选择字段 / 分量、色标范围模式 |
| 2 | 时间序列 | 033 时间步（≥ 2 步时出现） | 选中后播放栏聚焦，属性：步列表与时间值 |
| 2 | 质量诊断 | 现有网格质量结果 | 选中后在底部诊断面板展开 |
| 1 | 表面序列（020） | `AnimationSequence` | 打开 / 关闭序列，取代侧栏「时序动画」区 |

- 对象树由 Rust 侧提供只读树模型（`QAbstractItemModel` 投影），QML 只发选中、可见性、重命名等意图，符合「QML 不维护第二份已提交工程状态」。
- 「选中」和「激活」分开：单击节点只把它选为属性面板的对象，双击或按 Enter 才打开 / 切换页签，与现有文档工作区语义保持一致。
- 现有能力下每个体网格只有一个切面和一个着色；树结构为将来的多切面或等值面留位置，但阶段 2 不新增此类能力。

### 属性面板

按选中节点的类型显示，统一分三个页签（学 CFD-Post 的 Details）：

| 节点 | 属性 | 显示 | 信息 |
|---|---|---|---|

### 视口

- 页签在上；视口背景改为深色渐变（待决问题 Q1）。VTK 里绘制三样东西：方向标记（已有）、色标（`vtkScalarBarActor`，阶段 3）、可选的标题 / 时间文字。
- 空状态：无文档时没有原生视口内容，QML 可以在这块区域显示引导卡片（「导入网格」「打开工程」「最近工程」）。这要求无文档时原生表面不覆盖该区域，需在目标平台验证；如果不满足，就把引导卡片放进对象树的空状态里。
- 视口工具（视图预设、复位、截图）放在工具栏「视图」分组，加上快捷键，不再占侧栏。

### 播放栏

保留 033 的状态机和位置，只做视觉调整：SVG 图标（首 / 上 / 播放‑暂停 / 下 / 末 / 循环），循环用切换按钮并带「已开启」tooltip 和图标变化；时间标签改成 `t = 1.00 s（3/3）`；帧率框带 `fps` 后缀；长状态文字移到状态栏。无播放源时显示为禁用的细条，不再整栏隐藏，避免视口高度跳动（待决问题 Q6）。

### 色标

- 主色标由 VTK 在视口内绘制，跟着截图、录屏一起导出。位置默认在右侧竖排，带字段名、单位、范围模式标注（「全部时间步」或「当前步」），满足[可视化架构](../architecture/visualization.md)「色标需展示单位、范围和映射方式」。
- 属性面板里保留一个数值化的小色标（渐变条 + 最小 / 最大值 + 范围模式），用于编辑，不再作为唯一显示。
- 颜色图：默认沿用现有发散三段色；阶段 4 提供少量预设（如 Cool to Warm、Viridis、灰度），预设数据来自公开且许可明确的定义（待决问题 Q3 附带核验）。

### 诊断

底部面板的「诊断」页签承载网格质量结果表：指标、最小 / 平均 / 最大、超阈值单元数。点击某行在视口高亮对应单元，前提是现有拾取 / 高亮能力能支撑；不能时只展示表格，另建任务。「消息」页签汇总状态消息历史，「任务」页签显示后台任务列表和取消入口。

## 工作流

### 导入

1. 「导入」可以从工具栏、菜单、对象树空状态、Ctrl+I 进入，或把文件**拖放**到窗口（拖放待评估 Qt Quick `DropArea` 和原生视口区域的事件归属）。
2. 导入对话框改为紧凑两列：文件（可编辑、可粘贴，旁边是「浏览」）→ 自动识别格式和网格类型（显示「已识别：VTU 集合 · 3 个时间步」）→ 单位（显示「按包围盒推测：毫米」并可修改）→ 近似尺寸带单位。
3. 确定后在对象树新增节点并自动选中，属性面板显示「信息」页签，视口打开页签。导入失败时对话框不关闭，在字段旁显示错误，状态栏不重复。

### 切面

1. 选中体网格，点工具栏「切面」或在树节点右键「添加 / 显示切面」，树下出现「切面」节点并选中。
2. 属性面板：轴向预设按钮组（X / Y / Z / 视线）→ 位置滑块带数值、单位和范围 → 高级：法向三元组。
3. 切面计算中，节点显示进度点；失败时节点带警告图标，「信息」页签给出原因。

### 上色

1. 选中切面或网格，在属性「字段着色」中选字段和分量；工具栏的字段下拉是同一入口的快捷方式（学 ParaView）。
2. 视口内的 VTK 色标立即出现，标出字段、单位和范围模式；属性里可切换「全部时间步 / 当前步 / 自定义」。
3. 播放时色标按 033 的规则更新；字段在某一步缺失时，树节点显示警告，播放状态写到状态栏。

### 诊断

1. 「网格 → 质量诊断」或在资产节点右键「诊断」，底部面板展开到「诊断」页签。
2. 表格列出各指标统计（包含 032 的非正交性和偏斜度）；点击一行，若能力支持，在视口高亮超阈值单元。
3. 诊断结果作为资产的子节点保留，切换资产时诊断表跟着切换。

### 导出

1. 网格导出：选中资产 → 工具栏、菜单或右键「导出」→ 格式和单位对话框 → 后台任务进入「任务」页签，可取消。
2. 截图导出：工具栏「截图」→ 选项：分辨率倍率、是否透明背景（取决于 VTK 能力）、是否包含色标。色标由 VTK 绘制，默认随截图导出。
