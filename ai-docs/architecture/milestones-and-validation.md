# 里程碑、使用流程与验证

[架构总览](README.md)

## 当前状态

当前已有 Cargo → CMake → Qt/QML → VTK 链路、工程资产和 STL 场景。以下按最小可视化渲染测试仓库的能力组织验收，不沿用旧任务完成状态。STEP、体网格生成与修复保留 OCCT / Netgen 基础，但 adapter 存在不代表工程与界面闭环已经完成。实际进展与验证证据见[任务索引](../task-index.md)。

## M0：最小桌面集成

维护 Cargo 入口与 CMake native 构建，通过 C++ ViewModel 连接工程服务，显示轻量中文工作台和 VTK 视口。没有活动网格时保持空白，不创建默认模型。

验收：干净 / 增量构建可用，运行入口正确定位程序和资源；窗口调整大小、关闭及重新打开正常。记录实际工具链、平台与图形后端；构建或无头测试通过不等于真实窗口验收通过。

## M1：工程与 STL 资产

验证现有新建 / 打开 / 保存工程、STL 预检与导入、资产页签、按需加载、视角导航和 sidecar 持久化主链。

验收：单位与来源记录正确，非法输入、取消和过期完成不覆盖有效工程；保存重开后资产关系一致；关闭页签后资源按所有权释放。预检、加载和显示准备的后台路径分别验证，不能据此推断所有写入操作已经异步化。

## M2：STEP 与几何处理（后续集成）

在保留的 OCCT adapter 上接通工程中的 STEP 资产、单位与诊断、几何显示，以及实际需要的选择和几何处理。当前 native STEP 样例和读取接口是集成基础，未完成的 GUI / project 入口继续标明范围。

验收目标：简单模型的单位与几何摘要正确，失败保留旧资产；导入结果、来源修订和持久化身份一致。装配 / 颜色等附属元数据是否支持按实际实现明确，不承诺完整 STEP 语义保真。

## M3：网格生成与修复（后续集成）

使用 Netgen 生成表面 / 体网格，转换为自有 Mesh IR，提供必要参数、质量摘要和显示；网格修复按真实问题与选定算法单独接入。保留网格校验与生成 adapter 不代表已经提供修复入口。

验收目标：连接关系、单元方向和区域映射正确；容量受限，取消 / 失败保留旧网格；几何修订变化使派生缓存失效。修复使用有明确缺陷及预期结果的案例，保存重开后来源和网格关系保持一致。

## M4：可视化测试扩展（按需）

围绕实际模型增加显示方式、裁剪、选择，以及已求解结果数据的导入与字段展示。保留网格版本、材料 / 边界标签、节点 / 单元 / 区域关联、单位、时间步和来源的组合语义，见[模型与结果组合](study-and-automation.md)。相机导航已有实现，结果导入及其余显示能力仍需按实际格式接入和验收。

验收目标：视口尺寸、DPR、输入与 GPU 生命周期正确；新增字段明确节点 / 单元关联、单位、范围和缺失值语义。合成测试数据清楚标注，显示效果不被解释为物理计算结果。

## 当前使用流程与后续目标

1. 新建或打开工程，检查工程位置和资产保存方式。
2. 预检并导入 STL，检查单位、摘要与资源提醒。
3. 激活模型资产，调整视角；关闭 / 重开页签验证按需加载与空视口。
4. 保存并重开工程，检查清单与 sidecar 资产关系。
5. 后续完成 STEP 工程入口后，再验收几何导入与处理。
6. 后续完成生成 / 修复入口后，再验收参数、网格质量、显示与持久化。
7. 后续完成已求解结果导入后，核对网格版本、材料 / 边界标签、字段关联与单位，再验收字段和时间步显示。

## 验证分层

| 层次 | 验证重点 |
|---|---|
| 领域逻辑 | ID、单位、修订失效、请求相关性与失败保留 |
| 适配器 | STEP 读取、Netgen 输出、Mesh IR 转换、VTK 数据映射 |
| 跨语言边界 | 所有权、错误映射、后台完成与取消生命周期 |
| 界面与渲染 | 线程交接、窗口生命周期、资产切换、导航与资源释放 |
| 持久化 | 保存重开、损坏 / 缺失资产、迁移与失败恢复 |
| 部署 | 无开发环境路径启动、资源与动态依赖完整 |

按实际改动运行存在的检查，记录命令、结果与限制。仅文档调整检查链接、目录标注、能力状态和范围；真实 GPU 窗口单独验收；性能诊断如有需要另立任务。
